🧱 HTML for Beginners

HTML stands for HyperText Markup Language. It is the standard language used to create and structure webpages.

Remember: HTML mainly provides the structure of a webpage.

1. Basic HTML Structure

Every HTML webpage normally starts with a basic document structure. 

<!DOCTYPE html>
<html>

<head>
    <title>My First Website</title>
</head>

<body>

    <h1>Welcome to My Website</h1>

    <p>This is my first webpage.</p>

</body>

</html>

2. HTML Tags

HTML uses tags to tell the browser what different pieces of content are. 

<h1>My Website</h1>

<h1> is the opening tag.
My Website is the content.
</h1> is the closing tag.

3. Common HTML Tags

  • <h1> to <h6> — Headings
  • <p> — Paragraph
  • <br> — Line break
  • <hr> — Horizontal line
  • <img> — Image
  • <a> — Link
  • <button> — Button
  • <ul> — Unordered list
  • <ol> — Ordered list
  • <li> — List item
  • <form> — Form
  • <input> — Input field
  • <div> — Container

4. Links

<a href="https://example.com">
    Visit Website
</a>

The href attribute tells the browser where the link should go.

5. Images

<img src="picture.jpg"
     alt="A picture">

src specifies the image location.
alt provides alternative text describing the image.

🎨 CSS for Beginners

CSS stands for Cascading Style Sheets. CSS controls how HTML content looks.

Remember: HTML = Structure. CSS = Style.

1. Basic CSS

h1 {
    color: blue;
    font-size: 40px;
}

2. CSS Selectors

Element selector:

p {
    color: black;
}

Class selector:

.intro {
    color: green;
}

ID selector:

#title {
    color: red;
}

3. Useful CSS Properties

color: blue;

background-color: white;

font-size: 20px;

text-align: center;

margin: 20px;

padding: 20px;

border: 1px solid black;

4. Flexbox

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
}

⚡ JavaScript for Beginners

JavaScript is a programming language commonly used to make webpages interactive.

Remember: HTML = Structure. CSS = Style. JavaScript = Behaviour.

1. Variables

let name = "Alex";

let age = 20;

const country = "Ghana";

2. Conditions

let age = 18;

if (age >= 18) {
    console.log("You are an adult.");
} else {
    console.log("You are under 18.");
}

3. Functions

function greet(name) {
    console.log("Hello " + name);
}

greet("Alex");

4. Arrays

let fruits = [
    "Apple",
    "Banana",
    "Orange"
];

console.log(fruits[0]);

5. Making a Button Interactive

<button id="myButton">
    Click Me
</button>
const button =
    document.getElementById("myButton");

button.addEventListener("click", function() {

    alert("Button clicked!");

});
